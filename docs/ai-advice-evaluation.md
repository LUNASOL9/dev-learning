### 발견한 실패와 미확인 원인

500 세 건의 로그에는 다음 예외가 나타났다.

```text
tools.jackson.databind.exc.MismatchedInputException:
No content to map due to end-of-input
```

제공된 스택에서는 BeanOutputConverter와 ChatClient의 entity() 변환 과정에서 실패했다. DTO를 받은 뒤 실행하는 검증기에 도달하기 전의 실패 경로다. 변환에 전달된 내용이 비어 있었다는 점은 확인되지만, 원본 Ollama 응답·종료 이유·토큰 사용량은 수집하지 않았다. 토큰 한도 소진이나 추론 때문에 최종 답변이 누락됐다는 설명은 아직 가설이다. 502 한 건은 응답 본문이 없어 정확한 실패 경로를 확정하지 않는다.

CONTEXT 4096은 실행 중인 컨텍스트 크기이며 누적 이용량 잔액이 아니다. 생성 토큰 한도와 브라우저·서버의 시간 제한은 별개의 조건이다.

### 결정과 다음 단계

1. 집의 qwen3.5:4b에서는 추론 Off를 도움말 기능의 기본 후보로 선택한다. 이번 표본에서 대기 시간과 응답 성공 여부가 개선됐다.
2. 회사 qwen3:1.7b에도 같은 결과가 난다고 일반화하지 않는다.
3. 브라우저 제한 150초와 서버 read-timeout 120s의 원복 여부를 확인한다.
4. 실제 변환 예외의 범위를 확인하고 모델 응답 변환 실패를 사용자용 502 안내로 처리한다. 모든 예외를 무조건 502로 바꾸지 않는다.
5. 확인 위치·행동의 구체성과 근거 없는 환경 가정을 계속 평가한다. HTTP 성공률과 내용 품질을 분리해 기록한다.
